## 不兼容变更 / Breaking changes

- 移除环境变量 `MCSM_MCP_AUDIT`。审计日志固定写入 `config.json` 同目录的 `audit.log`。
  Removed the `MCSM_MCP_AUDIT` environment variable. The audit log is always `audit.log` next to `config.json`.
- 移除未写入文档的环境变量 `MCSM_MCP_HOME`。请用 `MCSM_MCP_CONFIG` 指定配置文件路径。
  Removed the undocumented `MCSM_MCP_HOME` environment variable. Use `MCSM_MCP_CONFIG` to point at the config file.

工具、工具参数、`config.json` 格式和提示文案均未改变。

Tools, tool arguments, the `config.json` format and messages are unchanged.

## 内部整理 / Internal cleanup

- `server.mjs` 只保留入口和工具定义；配置加载、面板 HTTP 客户端、实例查找、文件规则和输出整形拆到 `lib/` 下的五个模块。
  `server.mjs` keeps the entry point and tool definitions; config loading, the panel HTTP client, instance lookup, file rules and output shaping moved to five modules under `lib/`.
- 去掉重复实现和多余的防御性代码，安全不变量不变。
  Removed duplicated logic and redundant defensive code; the security invariants are unchanged.
- 文件工具的审计记录现在写入调用时给出的路径原文（此前非法路径记为 `(invalid path)`）。
  File-tool audit entries now record the path as given (invalid paths were previously logged as `(invalid path)`).

## 升级 / Upgrade

更新源码，执行 `npm ci --omit=dev`，重启 MCP 客户端。若 MCP 客户端配置里设置了 `MCSM_MCP_AUDIT` 或 `MCSM_MCP_HOME`，请删除；旧的审计日志不会被迁移。

Update the source, run `npm ci --omit=dev` and restart the MCP client. Remove `MCSM_MCP_AUDIT` or `MCSM_MCP_HOME` from the MCP client configuration if set; an existing audit log at the old location is not moved.
