## 文件修改 / File modification

- 新增 `write_file`，用完整文本覆盖已有文件；空文本可清空文件。
  Added `write_file` to overwrite existing files with complete text, including empty text to clear a file.
- 新增 `edit_file`，按字面文本精确替换；匹配数须等于 `expected_matches`（默认 1），避免误改。
  Added `edit_file` for literal replacement with an exact `expected_matches` count (default 1).
- 通过 `allow.write_files: true` 开启，默认关闭；独立于读取、控制台和电源开关。
  Enable with `allow.write_files: true`; off by default and independent of read, console and power permissions.
- 保留未修改内容、中文、BOM 和 CRLF；拒绝路径穿越、二进制文件以及超过 1 MiB 的原文件或修改结果。
  Preserves untouched text, Unicode, BOM and CRLF; refuses path traversal, binary files and existing/resulting files over 1 MiB.
- 审计记录操作、实例、路径和结果，不记录文件正文。中英文文档已同步更新。
  Audit entries record the operation, instance, path and outcome without file contents. English and Chinese docs are updated.

## 下载与安装 / Download and install

需要 Node.js ≥ 18。下载 ZIP 或 tar.gz 并解压，进入目录执行 `npm ci --omit=dev`，然后按 README 配置 MCP 客户端。发行包不包含 Node.js 或依赖。

Requires Node.js ≥ 18. Extract the ZIP or tar.gz, run `npm ci --omit=dev` inside the directory, then configure your MCP client using the README. Archives include neither Node.js nor dependencies.

同时提供 npm 安装包 `mcsm-mcp-secure-0.2.1.tgz` 和 `SHA256SUMS`。仅发布到 GitHub Releases，不发布到 npm registry。

An npm package (`mcsm-mcp-secure-0.2.1.tgz`) and `SHA256SUMS` are also attached. Published to GitHub Releases only, not the npm registry.

## 升级 / Upgrade

更新源码并重启 MCP 客户端。现有配置保持兼容；如需修改文件，在现有 `config.json` 的 `allow` 对象中添加 `"write_files": true`。保留其他配置和独立的 API Key 文件。

Update the source and restart the MCP client. Existing configurations remain compatible. To enable file modification, add `"write_files": true` to the existing `allow` object in `config.json`, preserving other settings and the separate API key file.

## 验证与限制 / Verification and limits

端到端模拟测试通过，覆盖读写开关、实例/节点限制、匹配检查、空文本、大小限制、换行保留及泄露扫描。文件修改尚未在真实 MCSM 面板上验证；完整状态见 [checklist.md](https://github.com/EvergardenRoxy/mcsm-mcp-secure/blob/v0.2.1/checklist.md)。

End-to-end mock tests cover permission switches, instance/node restrictions, match checks, empty text, size limits, newline preservation and leak scanning. File modification has not been verified on a real MCSM panel; see [checklist.md](https://github.com/EvergardenRoxy/mcsm-mcp-secure/blob/v0.2.1/checklist.md).

只修改已有文本文件，不创建文件或目录，不自动备份。面板不支持原子条件写入，请避免并发编辑同一文件。

Only existing text files can be modified; no file/directory creation or automatic backups. The panel has no atomic conditional-write API, so avoid concurrent edits to the same file.
